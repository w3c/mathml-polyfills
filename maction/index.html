maction selection and actions

Serve the repo root over HTTP (e.g. python -m http.server 8080) and open http://localhost:8080/maction/index.html so ES modules load.

MathML Core shows only the first child of maction. MathML 4 still requires the selected sub-expression (selection, default 1). maction/maction.js shows that child, and restores MathML 3 toggle and tooltip. statusline uses a page-owned status region and does not write window.status. input is not turned into an editor. The Before column is native MathML Core. The After column and the table below are transformed. The left column says what the right column should show. A right-column cell that does not match has a light red background.

Toggling only swaps visibility. A branch that was hidden during the first pass is not measured again, so polyfills that measure can be wrong for a child you reveal later. Each case shows the MathML being tested.
