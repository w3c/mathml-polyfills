maligngroup / malignmark alignment

Serve the repo root over HTTP (e.g. python -m http.server 8080) and open http://localhost:8080/malign/index.html so ES modules load.

Tests for MathML3 §3.5.5 alignment markers. malign/malign.js is registered on mtable:has(maligngroup) and runs before mtable/mtable.js: it measures each alignment group, then replaces every maligngroup/malignmark with a computed-width <mspace> so the groups line up vertically within each table column. The Before column is outside the transform scope (red outline); the After column is inside .malign-after (blue outline) and is transformed on load.
