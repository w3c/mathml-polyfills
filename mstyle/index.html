mstyle attribute defaults

Serve the repo root over HTTP (e.g. python -m http.server 8080) and open http://localhost:8080/mstyle/index.html so ES modules load.

MathML 3 lets mstyle change the default of presentation attributes for its descendants. MathML Core treats mstyle as an mrow and only inherits displaystyle, scriptlevel, mathcolor, mathbackground, mathsize, and dir. mstyle/mstyle.js copies the other attributes onto the elements that accept them (closest mstyle wins; an explicit value on the element wins). The Before column is outside the transform (red outline); the After column is inside .mstyle-after (blue outline).
